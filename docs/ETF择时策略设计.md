# ETF/宽基择时 + 卫星仓 策略设计（v1 设计稿）

> 设计：项目管理侧（PM/架构）　2026-10-17
> 背景：横截面选股路线在真实可交易口径下证伪（2016 后 bp_value 净超额 −1.59%、2 因子 combo 夏普 0.418）。
> 本设计改用「**低频择时 + 少量卫星**」，目标不是冲高收益，而是**风险调整后稳定跑赢宽基**。

---

## 零、为什么这个方向能成立（先讲清逻辑，不然实现会跑偏）

| 已证伪路径的痛点 | ETF 择时如何规避 |
|---|---|
| 横截面选股 2016 后无 alpha | **不做选股**，只做资产间配置 |
| ADV≥0.5 闸门打掉一半超额（买不进） | ETF 流动性极大，**容量问题消失** |
| 个股印花税 0.05%（卖出） | **ETF 免印花税**，成本只有佣金+滑点 → 低频策略的关键优势 |
| 退市股缺失导致 8-9% 幸存者偏差 | 指数/ETF **不存在退市**，偏差归零 |
| 回撤 50%、持续 3.8 年 | 分档仓位 + 债券/货币替代，目标回撤 ≤25% |
| 需盯盘、40 日调仓 | **月频/双周频**，低频匹配个人使用场景 |

**核心假设**：A 股择时（趋势+风险状态）在低频下有正期望，因为市场存在中期动量与波动聚集。

---

## 一、决策变量（实现前必须定死）

### 1.1 回测与实盘的分离（重要）

```
回测用【指数】    ：HS300(000300.SH) / ZZ500(000905.SH) / ZZ1000(000852.SH) / 创业板(399006.SZ) ...
                    —— 因为 ETF 上市晚、有折溢价与跟踪误差
实盘用【ETF】     ：510300.SH / 510500.SH / 512100.SH / 159915.SZ ...
成本按【ETF】算   ：买入 0.026% 佣金 + 0.01% 滑点 ≈ 0.036%；卖出同；**无印花税**
```

> ⚠️ 个股成本模型（`config/costs.yaml`）不能直接用于 ETF，必须单开一套。
> 这是最容易搞错的地方——用 0.177% 卖出成本去算 ETF，会把结论压死。

### 1.2 资产池（v1 建议 8 个，覆盖四类风险源）

| # | 类别 | 回测代理（指数） | 实盘标的（ETF） | 单资产上限 |
|---|---|---|---|---|
| 1 | A股大盘 | 沪深300 `000300.SH` | `510300.SH` | 40% |
| 2 | A股中小盘 | 中证500 `000905.SH` | `510500.SH` | 30% |
| 3 | A股小微盘 | 中证1000 `000852.SH` | `512100.SH` | 20% |
| 4 | 成长 | 创业板指 `399006.SZ` | `159915.SZ` | 20% |
| 5 | 红利/价值 | 中证红利 `000922.CSI` | `510880.SH` | 30% |
| 6 | 利率债 | 中债10年（或国债ETF代理） | `511260.SH` | 50% |
| 7 | 黄金 | 沪金主力/伦敦金 | `518880.SH` | 20% |
| 8 | 现金替代 | **货币ETF** | `511990.SH` | 100% |

**关键设计**：空仓不是持现金，而是持**货币ETF**（年化约 2%）。这一条能显著抬高空仓期收益，是专业做法与业余做法的分水岭。

### 1.3 调仓频率
- **默认月频**（每月最后一个交易日收盘定信号，次日 T+1 开盘执行）
- 偏离触发：单资产权重偏离目标 >10pp 或总仓位偏离 >20pp 时，次日补调
- 不做日内、不做周内

### 1.4 成本（ETF 口径，单开配置）
```
buy  = 0.00026（佣金，万2.6）+ 0.0001（滑点）= 0.036%
sell = 0.00026 + 0.0001                = 0.036%
往返 = 0.072%
（无印花税、无过户费；ETF 佣金常有最低 5 元/笔，资金小时需按笔数折算）
```

## 二、择时信号（3 类，必须正交，不许堆同类）

### 2.1 趋势/动量类（主信号，权重 60%）

| 信号 | 定义 | 用途 |
|---|---|---|
| `ma_state` | 收盘 vs MA60 / MA200 的状态（1/0） | 单资产多空态 |
| `mom_12_1` | 过去 12 个月收益剔除最近 1 个月 | 跨资产相对强度 |
| `mom_3m` | 过去 3 个月收益 | 短中期趋势确认 |

**跨资产排名**：对资产池内全部权益类，按 `mom_12_1` 排名，只持有前 K 名（K=2~3）。

### 2.2 风险状态类（权重 30%）

| 信号 | 定义 | 用途 |
|---|---|---|
| `vol_target` | 目标年化波动 15%；实际 20 日波动 >目标则降仓 | 仓位缩放（连续） |
| `dd_state` | 宽基距 250 日高点回撤：<10% 满档 / 10-20% 降档 / >20% 再降 | 分级降仓 |
| `corr_spike` | 池内资产 60 日平均相关系数分位 >80% | 系统性风险，整体降档 |

### 2.3 估值/情绪类（辅助，权重 10%，只做微调不加仓）

| 信号 | 数据来源 | 用途 |
|---|---|---|
| `pe_pct` | `valuation.db` 全市场 PE_TTM 分位数（或用指数 PE） | 极端高估时降档 |
| `turn_heat` | 全市场换手中位数分位 | 过热降温 |
| `zt_count` | 涨停家数分位（`tdx_snapshot` / `limitup.db`） | 情绪极端 |

> **纪律**：这三类信号必须各建各的，先用相关性验证两两 |ρ|<0.7，重复的合并。

## 三、仓位映射（信号 → 权重）

```
权益总仓位 E = base(趋势信号) × risk_scalar(风险状态) × val_scalar(估值微调)
   base        ∈ {1.0, 0.6, 0.3, 0}     ← 趋势：多头/中性/弱势/空头
   risk_scalar ∈ [0.4, 1.0]             ← 波动目标与回撤状态
   val_scalar  ∈ [0.8, 1.0]             ← 只在极端估值时打折

权益内部按 mom_12_1 排名分配，只持前 K 名，等权或风险平价
债券仓位 = (1 - E) × bond_weight（默认 0.5）
黄金   = min(0.15, (1-E) × 0.3)
货币ETF = 余额
```

### 硬约束（必须实现，不许放宽）
| 约束 | 值 |
|---|---|
| 单资产上限 | 见 1.2 表 |
| 权益总仓位上限 | 90% |
| 单日换手上限 | 30%（防止信号抖动导致过度交易） |
| 空仓期 | **必须持货币ETF**，不允许纯现金 |

## 四、卫星仓（v1 建议先留空，或 ≤10%）

### 设计原则
- 总权重 **≤10%**（不是 20%，因为个股策略已被证伪）
- 最多 **3 只**
- **只用通过严格口径的因子**：当前严格口径下可用因子可能是 **0 个**
  → 所以 v1 **建议卫星仓为空位**，等 2016+ 窗口的因子档案重建后再决定

### 若将来启用
- 触发条件：因子在新窗口下 三段同号 + 净超额>0 + 夏普≥0.5 + ADV≥0.5
- 单票止损 −15%
- 单票权重 ≤4%

> **这是纪律，不是保守**：我们刚被"看起来有效"的因子教训过，卫星仓必须先有可信的因子里程碑。

## 五、风控与执行

| 项 | 规则 |
|---|---|
| 最大回撤熔断 | 组合回撤 >20% → 权益仓位强制降至 40%；>30% → 降至 20% |
| 恢复规则 | 回撤修复至 10% 以内，逐档恢复（防锯齿） |
| 执行价 | **T+1 开盘**（月频下即次月首个交易日开盘） |
| 不可交易处理 | 标的停牌/一字板 → 顺延至下一可交易日，不得用信号价成交 |
| 再平衡 | 月频 + 偏离触发（见 1.3） |
| 记录 | 每次调仓必须落盘：信号值 / 目标权重 / 实际成交 / 偏差原因 |

## 六、验收标准（沿用 P0 建立的严格口径，但按 ETF 特性调整）

| # | 指标 | 门槛 | 说明 |
|---|---|---|---|
| 1 | 年化 | — | 不设绝对门槛，看相对 |
| 2 | **跑赢等权基准** | **≥3pp/年** | 基准 = 资产池等权（含债/金/货币） |
| 3 | **夏普** | **≥0.7** | 择时策略必须高于个股策略的 0.5 线 |
| 4 | **最大回撤** | **≤25%** | 这是主仓位，回撤是硬约束 |
| 5 | **Calmar** | **≥0.5** | 回撤 −25% / 年化 12.5% 才够 |
| 6 | **最大回撤持续** | **≤365 日** | 超过一年说明择时失效 |
| 7 | **三段 holdout 同号** | 2016-20 / 2021-26（2010-15 样本不足只作参考） | 与 P0 裁决一致 |
| 8 | 换手 | ≤6 次/年（月频自然满足） | 低频是核心优势，别做成高频 |
| 9 | 成本敏感性 | 2× 成本后仍跑赢基准 ≥1pp | 防"靠低换手撑住"的假象 |

**任一条不过 → 不进实盘**。

## 七、实施路线（分 5 步，每步有门禁）

### 步骤 0｜可行性验证（**必须先做，1 小时内出结论**）
- [ ] 通达信能否取 ETF 日线？测 `510300.SH`、`510500.SH`、`511990.SH`、`518880.SH`
- [ ] ETF 是否需前复权？取 `get_divid_factors` 看有无分红
- [ ] 各 ETF 历史起始日（510300 约 2012、512100 约 2016、511990 较晚）
- [ ] 指数代理数据是否齐全（399006.SZ 创业板指、000922.CSI 中证红利 是否有）
- **门禁**：若 ETF 或关键指数取不到 → 停止，回报，不要硬做

### 步骤 1｜单资产择时基线（最小可用）
- 只做 HS300 一个资产：`ma_state` + `vol_target` → 仓位 0~100%
- 产出：年化 / 回撤 / Calmar / 回撤持续，与"买入持有 HS300"对比
- **门禁**：必须比买入持有**回撤更低**，且 Calmar 更高。否则择时无效，回退

### 步骤 2｜多资产轮动
- 加入 ZZ500 / 创业板 / 红利 / 债券 / 黄金 / 货币
- `mom_12_1` 排名 + 风险状态缩放
- **门禁**：夏普 ≥0.7，回撤 ≤25%

### 步骤 3｜信号正交性检验与精简
- 计算所有信号两两相关，|ρ|≥0.7 的合并
- 消融：逐个移除信号，看夏普变化，**保留有贡献的**

### 步骤 4｜接入门户与决策链
- 新增 `/etf_timing` 页面：当前信号 / 目标仓位 / 上次调仓 / 历史净值
- 接入 L2 决策卡片（与现有 holdings / pitch 一致）

### 步骤 5｜纸上跟踪（Paper Trading）
- 先跑 3 个月纸上跟踪，不投真钱
- 对比"模型目标仓位" vs "实际可成交"，记录滑点与偏离

## 八、已知风险（实现前先认账）

| # | 风险 | 缓解 |
|---|---|---|
| R1 | **ETF 历史短**（512100 只有 2016 起），资产池早期不全 | 回测用指数代理；早期只用有数据的标的，并标注"资产池随年份变化" |
| R2 | **指数与 ETF 跟踪误差/折溢价** | 纸上跟踪阶段实测；回测结果打 0.9 折扣再判断 |
| R3 | **月频信号滞后**，错过快速反转 | 增加"偏离触发"作为补充（已有设计） |
| R4 | **择时容易被 2015/2018/2022 极端年打爆** | 回撤熔断 + 分档仓位；必须单独看这些年的表现 |
| R5 | **过拟合**：信号多、资产多、参数多 | 信号 ≤4 个、参数每类 ≤2 个；严格 holdout；禁止网格挑最优 |
| R6 | 货币ETF 数据可能缺失 | 用国债逆回购/银行理财收益率近似（年化 2%）兜底 |
