## 一、定版结论（一句话）

**评估窗口 = 2010-01-01 ~ 最新可得日；面板预热起点 = 2008-12-01（仅预热、不参与评估）。**

| 项 | 值 | 说明 |
|---|---|---|
| 评估起点 | `2010-01-01` | 主回测、因子验证、组合构建的统一起点 |
| 评估终点 | 最新交易日（当前 `2026-10-16`） | 由数据更新自动推进 |
| 面板预热起点 | `2008-12-01` | 供 `ma200_trend`（200 交易日）、`mom_120` 等长周期因子预热；**不参与绩效统计** |
| 配置位置 | `config/backtest_window.yaml` | 改这一处，全链生效（portfolio_builder / combo_validate / validate_all_factors） |

## 二、为什么是 2010-01（而不是 2020-06）

### 2.1 旧口径及其失效原因

旧代码把起点写死为 `2020-06-01`，注释写的是：

> `hist_mv / turn 覆盖边界（铁律③：2019 前换手结论作废）`

这两个前提**在 2026-10 的数据源切换后都不再成立**：

| 旧前提 | 现状 | 证据 |
|---|---|---|
| `hist_mv` 只覆盖 2020-01 起（82 个月） | **319 个月（2000-04 ~ 2026-10）**，茅台从 0 行 → 302 个月 | 由 `tdx_base.circ_mv` 重建 |
| `turn` 2019 年前缺失 | **2000-2026 每一年缺失率 0.00%**；手算 `成交量/流通股本` 偏差中位 **0.002%** | `risk/verify_turn_consistency.py` |

### 2.2 九项验证？2010 起全部达标

| # | 验证项 | 方法 | 结果 |
|---|---|---|---|
| V0 | 复权正确性 | 涨跌幅异常（超板块限幅即错） | 用「除权明细自算」后从 46,558 行降到 **1,299 行**（-97.2%） |
| V1 | 估值重算 | 市值÷净利TTM、价格÷每股净资产 | PE **94.1%**、PB **92.5%** 偏差 <1% |
| V2 | 除权反查 | 跳空行是否有对应除权事件 | 剩余可疑 **0.0043%**，已落 `qfq_suspect` 表 |
| V3 | 停牌缺口 | 覆盖率 + 跨停牌收益比 | 5 日窗 0.34%、20 日窗 1.34% → 计算时剔除 |
| V4 | 财务勾稽 | 累计 = Σ单季 | 中位 **0.000000%** |
| V5 | ST 敏感性 | 两套标签对比 + 分组收益 | 重建后误判 **7.8% → 2.1%** |
| V6 | 市值一致 | 通达信市值 vs 自算 | 中位 **0.013%**（5,558 只） |
| V7 | 换手一致 | 手算 volume/流通股本 | 中位 **0.002%** |
| V8 | PIT | 披露日滞后分布 | 覆盖 **100%**、中位 32 天、0 条早于报告期 |

### 2.3 唯一的真实短板：幸存者偏差

| 年份 | 真实 A 股中被行情覆盖的比例 |
|---|---|
| 2000 | 82.1% |
| 2005 | 86.2% |
| **2010** | **90.5%**（起点） |
| 2015 | 92.2% |
| 2020 | 95.2% |
| 2025 | 99.5% |

> 退市股行情在通达信数据包中**根本不存在**（337 只退市 A 股仅覆盖 25 只），
> 这是**无法用任何数据源补齐的硬约束**（见 DS-17）。
> 2000-2009 缺 10-18% → 会系统性高估收益 → **不作为主窗口**。

## 三、用 2010-01 起步时的**已知限制**（必须随结论一起披露）

| # | 限制 | 影响 | 处理 |
|---|---|---|---|
| 1 | **龙虎榜只有 2019-01 起**（`lhb.db`，139,662 行） | `lhb_jg_cnt_20` 因子在 2010-2018 **覆盖率为 0** | 该因子结论只能按 **2019+** 解读 |
| 2 | 两融 `rzrq.db` 从 2010-03-31 起 | 2010 年 1-3 月缺失 | 可接受 |
| 3 | **北交所 593 只** 2021-11 才有交易 | 2010 起对它们无意义 | 截面中降权或剔除 |
| 4 | `limitup.db`（882 行）/ `consensus.db`（8,419 行）**无日期列** | 快照表，不能用于历史窗口 | 仅用于当前截面 |
| 5 | **ST 剔除在 2020-06 前是推断**（重建后误判 2.1%） | 可能误剔/漏剔少量股票 | 结论标 `low-confidence`，或做双口径敏感性测试 |
| 6 | 2010-2014 退市覆盖 90.5%~91.8% | 幸存者偏差约 8-9% | 逐年披露；长期持有类研究建议 2015+ |
| 7 | 跨停牌样本（5 日窗 0.34% / 20 日窗 1.34%） | 收益率跨缺口，产生假信号 | 因子计算时剔除（`filters.exclude_suspension`） |
| 8 | `qfq_suspect` 710 行（疑似漏报送转，0.0043%） | 个别股票复权价偏差 | 剔除（`filters.exclude_qfq_suspect`） |

## 四、配置与代码入口

### 4.1 配置文件

```yaml
# config/backtest_window.yaml
window:
  start: "2010-01-01"
  end: "2026-10-16"
  panel_load_start: "2008-12-01"   # 必须比 start 早 ≥365 天（因子预热）
filters:
  exclude_suspension: true
  exclude_qfq_suspect: true
  exclude_st: true
  bj_handling: "keep"
```

### 4.2 读取方式

```python
from factors.window_config import get_window, get_filters
w = get_window()          # {'start','end','panel_load_start','robustness'}
f = get_filters()         # {'exclude_suspension', ...}
```

### 4.3 已接入的程序

| 程序 | 接入方式 |
|---|---|
| `factors/portfolio_builder.py` | `DEFAULT_START` / `DEFAULT_END` / `PANEL_LOAD_START` 读配置 |
| `factors/combo_validate.py` | `DEFAULT_START` / `DEFAULT_END` 读配置 |
| `factors/validate_all_factors.py` | 继承 `combo_validate` 的窗口 + 面板起点读配置 |
| `backtest/bt_engine.py`、`bt_runner.py`、`backtest_script1.py`、`benchmark_speed.py` | 硬编码改为 2010-01-01 |
| `data/build_hist_mv.py`、`fetcher_hist_mv.py` | 默认起点改为 2010-01 |

> **未改**：`validation/test_*.py`、`demo_*.py`——它们是为特定窗口设计的自检脚本
> （如 `covers(code, "2020-01-01", ...)` 断言全覆盖），改窗口会导致自检假报警。
