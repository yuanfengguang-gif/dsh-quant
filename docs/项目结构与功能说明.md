## 一、这是一个什么项目

**一句话**：自然语言驱动的 A 股 ETF 量化系统，服务于「红利低波 + 黄金 + 纳指」的养老组合管理。

**三层架构：**

| 层 | 由谁负责 | 干什么 |
|---|---|---|
| **驱动层** | 语言模型（AI） | 控制、挖因子、审计、牛散蒸馏、写报告 |
| **执行层** | 写死引擎（确定性 Python） | 评分、回测、风控、扫描 —— 结果可复现 |
| **事实层** | 数据系统 | 行情、估值、宏观，全部可追溯、可证伪 |

**三条硬约束（写在 `AGENTS.md` 里，AI 必须遵守）：**
1. **AI 不预测个股涨跌** —— 这是硬约束，不是选项
2. **所有数字必须可复现** —— 每份报告都要能追到脚本与数据
3. **只买 ETF，不买个股，不加杠杆，不做空**

**配比：**

### ② 卫星仓三信号（管 30% 卫星仓）

| 信号 | 卖出 | 买回 |
|---|---|---|
| 红利低波股息率 | ≤ 2.50% | ≥ 4.00% |
| 沪深300 股权风险溢价（ERP） | ≤ 0.50% | ≥ 3.50% |
| 沪深300 市净率（PB） | ≥ 2.10 | ≤ 1.50 |

**规则**：**任一**报警就卖；**至少两个**说便宜才买回；每月检查。

### ③ 黄金换红利两层闸门（v5，2026-10-26 用户确认）

```
第 1 层 估值闸门：红利价格指数 H30269 距历史高点 ≤ −25%
        → 已深度便宜，立即分 12 个月买

第 2 层 危机信号：沪深300 自本轮高点跌 ≥20% 且 自最低点反弹 ≥15%
        → 触发后分 12 个月买

兜底：36 个月未触发 → 不强制买入，继续卖金条生活
```

**规模**：换 **100 万**（分 12 个月每月 83,333 元），保留 **44 万**黄金底仓。
**换完股息**：56,000 元/年 = 每月 4,667 元，覆盖 5,000 元开支的 **93%**。

**依据**：R172 / R175 / R176（209 个历史起点回测：接近高点时买入，5 年最坏浮亏 −63.7%；等信号再买，最坏浮亏 −29.9%，终值反而更高 1.96 vs 1.37）

### ④ 危机信号仪表盘（25 指标库，v3.2）

**三组精选 15 个 + 3 个合成：**

| 组 | 指标 |
|---|---|
| **领先组（5）** | 垃圾债 vs 国债、新兴 vs 美股、波动率分位、美元动量、信用利差 |
| **美股结构组（5）** | 周期 vs 防御、金融股相对、垃圾债动能、等权 vs 市值权、高beta vs 低波 |
| **A股本土组（5）** | 两融余额分位、两融3月变化、全A市盈率分位、全A市净率分位、沪深300成交额分位 |
| **合成（3）** | 美股综合（19 指标）／ A股综合（6 指标）／ 领先5合成 |

**定位（必须理解）：** 这不是预警雷达，是**体检报告**。
- 领先期只有 **2–4 个月**（相对**底部**），相对**顶部**是**滞后 4–9 个月**
- 危机前 6 个月的分位只有 26%–75%（接近抛硬币）
- 所有合成指标触发时，A股已平均跌 30%–42%
- **真实价值在内部分化**：内部指标（周期/金融/垃圾债）先坏、表层（信用利差/波动率）后坏

### ⑤ 模拟盘（每交易日 16:30 自动）

## 五、数据源优先级（A 股 / ETF）

**用户 2026-10-23 明确：通达信 > 腾讯 > 新浪 > 东财**

| 优先级 | 来源 | 说明 |
|---|---|---|
| **1** | **通达信官网盘后包** | `tdx.com.cn`，每交易日 1 个包约 2.6MB，含沪深北全市场。当日包通常收盘后数小时发布 |
| **2** | **腾讯 K 线** | `ifzq.gtimg.cn` 三入口互备，零鉴权、不封 IP、当日收盘后可取 |
| **3** | 新浪 | 全历史兜底 |
| **4** | 东财 | 仅末位兜底（最容易 `RemoteDisconnected`） |

**美股**：`ak.stock_us_daily`；美元折算用中行中间价 `usdcny.csv`（比美股晚 1 天，需前值延续）。

## 八、重要提醒（踩过的坑）

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | 改 `deck_server.py` 路由后不重启 → 页面 404 | **改完必须重启**，并用真实浏览器验证 |
| 2 | 改 `pension_api.py` 等被 import 的模块后不重启 → 显示旧内容 | **Python 缓存 `sys.modules`，改文件不等于生效** |
| 3 | 面板 CSS 路径写成 `ui_v2/core/` | CSS 在 **`ui_v2/assets/`**，`core/` 只有 `api.js` / `render.js` |
| 4 | 用东财接口取 A 股行情 | **通达信/腾讯优先**，东财只做兜底 |
| 5 | 用「名义10Y − CPI」算实际利率 | **黄金用官方 TIPS 实际收益率**（两者相关仅 0.489） |
| 6 | 用「全收益指数」判断红利贵不贵 | 全收益因分红累积几乎永远创新高，**要用价格指数 H30269** |
| 7 | 分析分红资产 vs 非分红资产时用不复权价 | **必须用全收益/复权数据**，否则少算 5%+/年 |
| 8 | 只看最终收益评价择时策略 | **必须看买入后的最大浮亏**（路径风险） |
| 9 | 全期回测出好结果就下结论 | **必须做样本外检验**（本项目 2 次因此发现过拟合） |
