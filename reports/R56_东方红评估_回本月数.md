## A · 东方红红利低波评估

### A.1 基本信息

| 项 | 值 |
|---|---|
| **代码** | **012708**（A 类）/ **012709**（C 类）/ 025518（D 类，数据未取到） |
| **全称** | 东方红中证**东方红**红利低波动指数证券投资基金 |
| **跟踪指数** | 东方红定制指数（非中证红利低波动 100） |
| **成立** | **2021-12-30**（仅 4.8 年） |
| **规模** | A 类 **35.65 亿** + C 类 **28.36 亿** ≈ 64 亿 |
| **基金公司** | 上海东方证券资产管理 |
| **基金经理** | 徐习佳、高原 |
| **类型** | **股票型-标准指数（场外基金，非 ETF）** |

### A.2 🔴 关键限制：场外基金，不适合我们的操作方式

| 差异 | ETF（现有持仓） | 场外基金（东方红） |
|---|---|---|
| 交易方式 | 交易所实时买卖 | 申购/赎回 |
| 到账时间 | T+0（卖出即可用） | **T+1 / T+2** |
| 定价 | 实时市价 | **每日一个净值** |
| 择时精度 | 可分笔、可挂单 | 只能按当日净值成交 |
| 费率 | 佣金约 0.036%/边 | 申购费/赎回费（A 类通常 0.1-1.2%） |

**我们方案要求「每月检查股息率分位、触发即全卖/全买」。场外基金的 T+1/T+2 与单一定价，会显著降低择时精度。**

| 基金 | 年化 | 回撤 | **Calmar** |

| 红利低波100ETF景顺（515100） | 6.25% | −12.9% | 0.484 |
| 红利低波50ETF南方（515450） | 8.73% | −13.6% | 0.642 |
| **红利低波ETF华泰柏瑞（512890）** | **9.79%** | −14.0% | 0.699 |

**三个发现：**

| # | 发现 |
|---|---|
| **1** | **东方红收益不占优**：8.65% 低于南方（8.73%）和 512890（9.79%） |
| **2** | **但回撤最小**（−11.8%），Calmar 0.733 最高 —— 这是它唯一的优势 |
| **3** | 🔴 **光总说「华泰柏瑞跑输前两只」，与我们数据相反**：同区间 512890 年化 9.79% 是三只最高 |

**对第 3 点的可能解释：**
- 他用了不同时间段
- 或混淆了「ETF 二级市场价格」与「基金净值」
- 或他看的是「不含分红的净值增长」而 ETF 二级市场价格含分红再投

### A.5 判定：不替换，列为观察项

| 考量 | 结论 |
|---|---|
| 收益 | ❌ 不如现有 512890 和 515450 |
| 回撤 | ✅ 最小（−11.8%） |
| 样本长度 | ❌ **仅 4.8 年**，未经历 2018 熊市 |
| 交易方式 | ❌ **场外，T+1/T+2**，不适合每月择时 |
| 规模 | 🟡 64 亿，可接受但远小于 512890 的 314 亿 |
| 编制方法 | ✅ 光总认为最优（ROE + 预期股息率 + 周频波动率） |

**6 项里 2 项明显劣势（收益、交易方式），2 项优势（回撤、编制），判定「不替换，观察」。**

## B · 账户浮亏转正所需月数（已加入监控工具）

### B.1 指标来源

穷诸葛「红利之道三-节奏的账」提出：
- 一次投入（2015-06 高点进场）：**89 个月**才转正
- 分批 12 个月：**14 个月**
- 定投 60 个月：**13 个月**

**「价格回到起点」与「账户浮亏转正」是两件事** —— 后者要算上后续投入的成本。

### B.2 我们计划的实测（211 个历史起点）

**模拟**：10 万分 3 个月投 + 第 12 个月投 140 万，共 150 万

| 统计量 | 月数 | 年数 |
|---|---|---|
| **中位** | **12** | **1.0** |
| P75 | 12 | 1.0 |
| **P90** | **14** | **1.2** |
| P95 | 18 | 1.5 |
| **最坏** | **33** | **2.8** |
| 最好 | 12 | 1.0 |

**分布：**

| 转正月数 | 起点数 | 占比 |
|---|---|---|
| **=12（投完即正）** | 159 | **75.4%** |
| 13-18 | 41 | 19.4% |
| 19-24 | 8 | 3.8% |
| 25-36 | 3 | 1.4% |

**建仓期最深浮亏**：中位 −10.2%，P10 −40.2%，最坏 −60.8%

**最坏 5 个起点：**

| 起点 | 转正月数 | 最深浮亏 |
|---|---|---|
| 2010-09 | **33** | −22.0% |
| 2010-11 | 28 | −19.0% |
| 2007-06 | 26 | −52.2% |
| 2011-03 | 23 | −19.6% |
| 2007-08 | 22 | −40.3% |

### B.3 🔑 这个数据对我们的意义

| 对比 | 回本月数 |
|---|---|
| 穷诸葛测的一次投入（2015-06 高点） | **89 个月** |
| 穷诸葛测的分批 12 个月 | 14 个月 |
| **我们的计划（中位）** | **12 个月** |
| **我们的计划（P90）** | **14 个月** |
| **我们的计划（最坏）** | **33 个月** |

**我们的计划回本速度优于「分批 12 个月」，因为「等 12 个月」本身就在等更好的价格 —— 投完时通常已接近成本。**

**这正是 v5 说的「慢的代价是少赚，收益是回本快」的量化证据。**
