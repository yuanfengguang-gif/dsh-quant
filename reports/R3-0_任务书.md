## 三、6 个候选触发器（精确定义，不许改）

| ID | 名称 | 触发条件（全部用当日及以前数据） |
|---|---|---|
| **T1** | 波动率高位 | `vol20` 的 750 日滚动分位 **> 90%**；`vol20 = std(日收益,20) × √252` |
| **T2** | 波动率极端 | 同 T1，但分位 **> 97%** |
| **T3** | 趋势破位 | `close < MA250` **且** `close / rolling_max(close,250) − 1 < −20%` |
| **T4** | 杠杆收缩 | `(融资余额/流通市值)` 的 **20 日变化 < −5%**（仅 2016+，样本不足须标注） |
| **T5** | 相关性**相对抬升**（v1.1 修订，原"绝对>0.80"已废弃） | `(4 指数 60 日平均两两相关) − (该值过去 250 日中位数) > 0.05` |
| **T6** | 组合（波动+趋势） | **T1 AND T3** 同时成立 |

### 触发段定义

连续触发日算**一个触发段**，取首日为 `t0`；条件失效日为该段结束。
> 例：T1 在 2015-06-15 到 2015-09-30 连续成立 → 记为 1 段，t0 = 2015-06-15。

## 四、每个触发段要算什么（评估口径）

| 指标 | 定义 |
|---|---|
| `t0` | 该段首日 |
| `dd_at_t0` | t0 收盘距过去 250 日最高点的回撤（%），正数表示回撤幅度 |
| `ret_20 / 60 / 120` | 指数在 t0+20/60/120 个交易日的收益（%） |
| **命中** | `ret_60 < 0` → 认为"成功避开了一次下跌" |
| **误报** | `ret_60 > 0` → 认为"错误减仓，错过上涨" |
| `fwd_max_dd_60` | t0 之后 60 日内的最大回撤（%） |

## 五、降仓模拟（**本轮最关键的产出**）

对每个触发器，用**固定规则**模拟（不许调参）：

```
非触发状态：仓位 100%
触发状态  ：仓位 50%（t0 次一交易日开盘执行，含成本）
成本      ：ETF 口径 config/costs_etf.yaml（买 0.036% / 卖 0.036%）
```

输出每个触发器的：

| 指标 | 说明 |
|---|---|
| 年化 / 夏普 / 最大回撤 / Calmar | 与「买入持有」对比 |
| 年触发次数（均值） | 频率，越高说明误报越多 |
| 累计在触发状态的天数占比 | 保费成本 |
| 分年收益 + 分年超额 | 必须能看出 2007/2009/2019/2024 牛市代价 |

## 十一、PM 预备验证（v1.1 追加，2026-10-18）

> 下发后 PM 自查发现 **T5 原定义有缺陷**，已修订。以下为证据，实现方无需重做，直接按修订版执行。

### 11.1 T5 原定义（绝对阈值 0.80）被证废

用 index.parquet（HS300/ZZ500/ZZ1000/SZ，2010-01~2026-10，4,074 天）实测：

| 阈值 | 触发天数占比 |
|---|---|
| >0.70 | **98.1%** |
| >0.75 | 94.5% |
| **>0.80（原设计）** | **90.2%** |
| >0.85 | 75.6% |
| >0.90 | 49.8% |
| >0.95 | 7.1% |

**分场景（原设计 0.80）**：2015 股灾 100% / 2018 贸易战 89.1% / 2021-24 慢熊 88.2% /
**2019 牛市 100% / 2020-21 牛市 100%** —— **危机与牛市没区别，无区分度**。
> 若照原设计执行，T5 等于"永久减仓"，模拟结果会退化为"长期 50% 仓位"，毫无信息量。

### 11.2 T5 修订为"相对抬升"后表现良好

指标：60日平均两两相关 − 过去250日中位相关，阈值 **>+0.05**（总触发占比 15.2%）

| 场景 | 触发占比 | 中位抬升 | 评价 |
|---|---|---|---|
| **2015 股灾** | **79.1%** | **+0.094** | ✅ 强命中 |
| **2018 贸易战** | **71.7%** | **+0.076** | ✅ 强命中 |
| 2021-24 慢熊 | 13.0% | −0.007 | 不触发（阴跌非相关性事件，合理） |
| **2019 牛市** | **0.0%** | −0.010 | ✅ 零误报 |
| **2020-21 牛市** | **0.0%** | −0.000 | ✅ 零误报 |
| 2024-25 | 24.5% | — | 中等 |

> 对照：绝对阈值 0.95 在 2015 只覆盖 10.4%、2018 12.8%，但在 2024-25 触发 24.5% —— 覆盖差且错位。

### 11.3 T1/T2 的数据可用性限制（必须在报告中标注）

ol20 的 750 日滚动分位需要 750 个交易日历史：
- ol20 有效起点 2005-02（早期有缺失）
- **滚动分位最早可用约 2008-01**
- → **2007-10 顶部时 T1/T2 无法评估**，表 3 的 2007 行须标注"数据不足"，不得填 0
