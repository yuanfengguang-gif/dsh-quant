## 零、🔴 首先认错：R39 的 S1 结果是 bug

### 错误

R39 的 `evaluate()` 里有这一行：

```python
full = d[col].to_numpy(float)      # col 已经是"分位值"
pct = rolling_pct(pd.Series(full), 750)   # 又算了一次分位！
```

**对一个已经是"分位"的序列再算分位 = 双重平滑，导致结果虚高。**

### 后果

| 指标 | R39（bug 版） | R40（正确版） |
|---|---|---|
| S1 年化 | 13.58% | **9.10%** |
| S1 回撤 | −36.4% | **−53.8%** |
| S1 Calmar | 0.373 | **0.169** |

**我把一个 Calmar 0.169 的信号误报成"目前最好的信号"。**

### 教训

**信号计算链必须检查"输入是否已是变换后的量"**。同类错误在 E12（未验证推断当结论）之后又一次发生，登记为新错误 **E15**。

**修正后：R39 的「分档结果」是正确的（那部分用的是原始分位值做 qcut），只有「策略结果」错了。**

## 二、🔑 核心发现：预测力 ≠ 可交易性

| 信号 | 与未来 1 年收益相关系数 | 策略 Calmar | 结论 |
|---|---|---|---|
| **S3 ERP = 1/PE − 10Y** | **+0.439**（最强） | 0.312（最差） | **能判断贵贱，不能择时** |
| S5 PE 动量 | −0.214 / −0.239 | 不一致 | 同上 |
| S4 利差 | +0.227 | ≈ 无差异 | 同上 |
| S1 拥挤度 | −0.062 | 0.169 | 两者皆无 |
| S2 波动率 | +0.016 | — | 无 |

### 为什么 S3 预测力最强却最不能交易

1. **ERP 高 → 未来 1 年收益高**（相关系数 0.439，统计上成立）
2. **但 ERP 高时往往持续很久**（利率下行期），策略在这个状态"满仓"是对的
3. **问题在 ERP 低时降仓到 30%** —— 而 ERP 低的时段很短、幅度大，错一次代价巨大
4. **样本只有 2018+（8 年）**，无法验证极端情形

### 结论

**S3 的正确用法是「估值温度计」（判断当前贵贱），不是「交易信号」（决定仓位）。**

如果需要用它，应该：
- **温和倾斜**：ERP 分位 <30% 时降到 80%（不是 30%）
- **不做频繁调仓**
- **明确标注：未经验证，仅作参考**

## 四、为什么"加信号"这条路走不通（结构性原因）

| 原因 | 说明 |
|---|---|
| **1. 红利低波本身波动大但长期向上** | 满仓 Calmar 0.239，任何降仓都会损失复利 |
| **2. 择时信号的"正确率"要求极高** | 降仓 70% 时，只要错一次就抵消多次对 |
| **3. 样本量不足** | 20 年只有 5-6 次大危机，无法统计验证 |
| **4. 多重比较** | 测 13 个信号，1-2 个"显著"是随机期望 |
| **5. 估值指标与收益的关系非单调** | 股息率倒 U 型、ERP 只在极低时有效 |

**这与 Track A（横截面因子 0/39 有效）的结论一致：这个市场的无效性不够大到能稳定套利。**
