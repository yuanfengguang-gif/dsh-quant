## 二、四件任务

| 要求 |
|---|
| 查明是**数据缺失**还是**真实收益** |
| 若缺失 → 补齐；若真实 → 说明原因 |
| 该问题会影响 2025 年的"红利低波均值超额"，必须修正 |

### 任务 2：取通胀数据（🔴 前置依赖）

| 要求 |
|---|
| 取 **2007-01 ~ 2026-10 的中国 CPI 月度同比**（数据源：国家统计局 / akshare `macro_china_cpi_monthly`） |
| 构建**月度累计通胀指数**（以 2007-01 = 100） |
| 报：数据起点、频率、缺失率、累计通胀率（分段：2007-2015 / 2016-2026） |
| **若取不到 → 用固定 2.5%/年 做敏感性，并在报告中明示"未取到真实 CPI"** |

### 任务 3：⭐ 通胀调整后的提款测试（本轮核心）

对 R5-2 的 24 只 ETF 重跑，**同时报名义与实际**：

| 提款规则 | 定义 |
|---|---|
| **A. 固定名义金额** | 每年提初始本金的 4%（R5-2 已做） |
| **B. 通胀调整** | 每年提款额 = 初始 × 4% × 累计通胀指数（**保持购买力恒定**） |
| **C. 按净值比例** | 每年提当前净值的 4%（金额随净值浮动） |
| **D. 只花分红不卖份额** | 提款额 = 当年实际分红；不足部分不补（本金不动） |

**必报：每只 × 每种规则 × 提款率 4% 的：**

| 指标 | 说明 |
|---|---|
| 存活月数 | 是否耗尽 |
| **期末名义本金%** | — |
| **期末实际本金%（折算到起始年购买力）** | **核心指标** |
| 期间提款总额（名义 / 实际） | 真正拿到手多少 |
| 最大回撤 | — |

## 七、PM 预判（跑完逐条对照）

| # | 预测 |
|---|---|
| P1 | **通胀会让"期末本金 131.8%"降到 90% 左右**（510880，19.8 年） |
| P2 | 规则 B（通胀调整提款）比 A 更快耗尽本金，但购买力有保障 |
| P3 | 规则 C（按净值比例）本金几乎不会耗尽，但**提款额波动极大**（熊市年骤降） |
| P4 | 规则 D（只花分红）**多数 ETF 覆盖不足 100%**，需卖份额补足 |
| P5 | **滚动 3 年覆盖度会比单年稳定得多**，全年覆盖可能达 90-100% |
| P6 | **组合 P4（三只等权）的分红月份能覆盖 10-12 个月**（因三只分红月不同） |
| P7 | 组合 P4 的回撤低于单只（行业分散生效） |
| P8 | CPI 累计 2007-2026 约 **40-50%** |

> 若 P6 成立（覆盖 10-12 个月），**"每月分红"就能靠 3 只组合实现**，不用「自造分红」。
> 若 P6 不成立，则必须用「卖出份额补足」，我会在结论中明确。
