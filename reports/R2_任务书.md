## 二、诊断与推送（按顺序执行，逐步记录输出）

| 步 | 命令 | 记录什么 |
|---|---|---|
| 1 | `git remote -v` | origin 指向的 URL |
| 2 | `git log --oneline -5` | 本地最近 5 个提交（应含 cacd6be/67fbc96/4540c0e） |
| 3 | `git status` | 是否干净 |
| 4 | `git rev-parse HEAD` | 本地 HEAD 完整 hash |
| 5 | `git fetch origin` | 报错原文（如有） |

| 7 | `git ls-remote origin master` | 远端 HEAD 完整 hash |

| 6e | `git push origin master` | 重试 |

### 若第 6 步报凭据错误（403 / Authentication failed）

| 步 | 命令 | 说明 |
