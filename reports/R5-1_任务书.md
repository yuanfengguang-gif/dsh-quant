## 四、基础测算（全部列出，不排名）

### 4.1 三口径涨跌（**必须三种都报**）

| 口径 | 定义 | 用途 |
|---|---|---|
| **不复权（PR）** | 原始收盘价 | 反映"只卖不投"的实际价格 |
| **前复权（qfq）** | 除权后向前调整 | 常用看盘口径 |
| **后复权（hfq）** | 向后调整，含分红再投资 | **反映"分红再投"的真实回报** |

每只报：全期累计收益 / 年化 / 波动 / 最大回撤 / 夏普 / Calmar / 区间起止。

> **三种口径的差异 = 分红的贡献。** 这是本轮最重要的对照。

### 4.2 分红档案（每只）

| 字段 | 说明 |
|---|---|
| 分红次数 / 首次 / 最近一次 | — |
| **分红月份分布** | 12 个月各分了几次 |
| 每次每份金额（元） | 完整列表 |
| **TTM 分红总额** | 过去 12 个月合计 |
| **股息率（TTM）** | TTM 分红 ÷ 当前价格 |
| **分红连续性** | 近 5 年是否有中断 |
| 分红金额变异系数 | 衡量稳定性（越小越稳） |

### 4.3 费率与成本

| 字段 | 说明 |
