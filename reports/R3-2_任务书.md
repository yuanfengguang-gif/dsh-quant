## 四、🔴 本轮核心：五项稳健性检验（缺一不可）

### 检验 1：逐年分解（**最重要**）

> 问题：+3.37%/年 是来自**多年稳定累积**，还是**两年运气**？

必报：`2011, 2012, ..., 2026` 逐年的 **策略收益 / 基准收益 / 超额**，并计算：

| 指标 | 定义 |
|---|---|
| **正超额年份占比** | 超额 >0 的年份 / 总年份 |
| **超额集中度** | 前 2 大正超额年份之和 / 全部正超额之和（**>60% = 靠运气**） |
| **最大单年贡献** | 单年超额 / 累计超额 |

### 检验 2：阈值邻域（预注册 3 点，**不许搜索最优**）

T5 的 `+0.05` 阈值换成 **`+0.03 / +0.05 / +0.07`** 三个值，各自报完整结果。

| 禁止 | 说明 |
|---|---|
| ❌ 不许报"最优是 X" | 只报三个值的结果表 |
| ❌ 不许扩大搜索范围 | 就这 3 个点，不多不少 |
| ✅ 要求 | **三个值结论方向必须一致**，否则说明 T5 依赖精确阈值 = 过拟合 |

### 检验 3：成本与换手敏感性

T5-D0 意味着 **100%→0%→100%** 的往返，成本可能吃掉收益。

| 场景 | 单边成本 |
|---|---|
| 基准 | 0.036%（ETF） |
| 加倍 | 0.072% |
| 三倍 | 0.108% |

必报：**年换手次数、累计成本拖累、成本 3 倍后是否仍为正超额**。

### 检验 4：无未来函数验证（防止"偷看"）

必须输出：
1. `T5_signal` 完整日序列（0/1），**首次为 1 的日期必须 ≥ 2011-09-06**
2. 触发日 `t` 的执行记录：信号用 `≤t` 的数据，**仓位在 `t+1` 开盘变化**
3. 抽样 5 个触发点，输出「触发日 t 的 60 日相关 / 250 日中位 / 抬升幅度」三个原始数

### 检验 5：与"简单策略"对比（避免把 beta 当 alpha）

| 对照 | 说明 |
|---|---|
| 买入持有 | 已有 |
| **恒定 80% 仓位** | T5-D0 的等效仓位约 79.3% |
| **恒定 60% 仓位** | 更保守的对照 |
| **年线择时（MA250 简单版）** | 最朴素的择时，若 T5 打不过它就没价值 |

必报：这 4 个对照 + T5-D0/D20 的 **年化 / 夏普 / 回撤 / Calmar** 同表。

## 六、门禁（本轮验收标准，先定后看）

| # | 门禁 | 阈值 |
|---|---|---|
| **G1'** | 主窗口（2011-09+）最大回撤改善 | **≥ 10pp** |
| **G2'** | 主窗口内牛市年份（2014/2019/2020/2025）合计超额 | **≥ −15pp** |
| **G3'** | **修正 G3**：回撤匹配下的年化增益 | **≥ +2.0pp/年** |
| **G4'** | 阈值邻域（+0.03/+0.05/+0.07）| **三个值全部正增益且方向一致** |
| **G5'** | **超额集中度** | 前 2 大年份占正超额 **< 60%**（否则视为运气） |
| **G6'** | 成本 3 倍后 | 仍为正超额 |
| **G7'** | 打赢简单策略 | 夏普 > MA250 择时 **且** > 恒定 80% |

### 判定规则（PM 预先声明，不许事后改）

| 结果 | 结论 |
|---|---|
| G1'~G7' 全过 | ✅ **T5 成立** → 进 R4 组合设计（保险层 + 卫星仓） |
| G4'/G5' 不过（依赖精确阈值 或 靠少数年份） | ❌ **过拟合** → T5 作废，本路线收口 |
| G3' 不过 | ❌ 触发器无额外价值 → 用恒定仓位 |
| G7' 不过（打不过简单策略） | ❌ 复杂度不值 → 用 MA250 或恒定仓位 |
| G6' 不过 | ❌ 成本吃掉收益 → 收口 |

| # | 预测 | 说明 |
|---|---|---|
| P1 | 主窗口（2011-09+）T5-D0 的回撤改善 **会小于 6.9pp** | 因为 2011-2016 段 T5 效果未知，可能拖累 |
