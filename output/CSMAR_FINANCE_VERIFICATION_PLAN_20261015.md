## V1 内部一致性（最重要，零成本，覆盖全量）

财务数据必须满足会计恒等式，任何违反都是明确错误。

### 1.1 资产负债表恒等式
| 检查 | 公式 | 通过标准 |
|---|---|---|
| 资产构成 | 流动资产 + 非流动资产 = **资产总计** | 相对偏差 < 1% |
| 负债构成 | 流动负债 + 非流动负债 = **负债合计** | 相对偏差 < 1% |
| **会计恒等式** | 资产总计 = 负债合计 + **股东权益合计** | 相对偏差 < 1% |

### 1.2 利润表勾稽
| 检查 | 公式 | 通过标准 |
|---|---|---|
| 毛利 | 营业收入 − 营业成本 = 毛利 | 相对偏差 < 1% |
| 毛利率 | 营业毛利率 ≈ (营收−成本)/营收 | 绝对偏差 < 0.5pp |
| 归母净利 | 归母净利 = 净利润 − 少数股东损益 | 相对偏差 < 2% |

### 1.3 跨表勾稽
| 检查 | 公式 | 通过标准 |
|---|---|---|
| **ROE** | 净资产收益率 ≈ 归母净利 / 股东权益 | 绝对偏差 < 5pp |
| **ROA** | 总资产净利率 ≈ 净利润 / 资产总计 | 绝对偏差 < 3pp |
| **EPS** | 基本每股收益 ≈ 归母净利 / 总股本 | 相对偏差 < 3%（股本取自通达信） |
| 资产负债率 | 资产负债率 ≈ 负债合计 / 资产总计 | 绝对偏差 < 1pp |

### 1.4 时间序列自洽
| 检查 | 公式 | 通过标准 |
|---|---|---|
| 增长率 | 净利润增长率 = (本期−上期)/\|上期\| | 绝对偏差 < 5pp |
| **季度加总** | 全年累计 = Q1 + Q2 + Q3 + Q4（单季） | 相对偏差 < 1% |
| 连续性 | 无年份跳跃（除新上市） | 人工审阅 |

## V2 vs 项目现有 finance.db（零成本）

项目已有 `finance.db`（319,089 行，akshare 源）+ `finance_quality.db`（12,375 行，含 pub_date）。

| 检查 | 方法 |
|---|---|
| 同股同年对比 | 按 (code, period) 关联，比较 `revenue` / `net_profit` / `eps` / `roe` |
| 偏差分布 | 计算相对偏差中位数、P90、最大值 |
| 结论判读 | 偏差 < 2% → 一致；系统性偏差 → 口径差异；随机大偏差 → 需查源 |

**注意**：akshare 本身可能有错（是我们要替换的对象），所以 V2 只能作**参考**，不能作**判据**。

## V3 vs 通达信 PE/PB 反推（零成本，独立源，推荐）

**这是最巧妙的一招**：通达信日 K 自带 `pe_ttm`、`pb`，且与 CSMAR 是**完全独立的两个源**。

```
反推 EPS  = 收盘价 / PE_TTM
反推 净资产/股 = 收盘价 / PB
```

| 检查 | 方法 | 通过标准 |
|---|---|---|
| EPS 一致性 | 通达信反推 EPS vs CSMAR EPS（TTM 口径需对齐） | 相对偏差 < 15%（PE 有口径差异） |
| 净资产一致性 | 通达信反推 BPS vs CSMAR（净资产/股本） | 相对偏差 < 10% |
| 趋势一致性 | 两者算出的 ROE 时间序列是否同向 | 相关系数 > 0.8 |

**优势**：通达信是完全独立的商业数据源，两者吻合 → 强证据。

## 关键设计：PIT（时点对齐）验证

CSMAR 有 `年报公布日期`，这是**根治 F-5 前视偏差**的关键。必须验证：

| 检查 | 方法 |
|---|---|
| 披露日合理性 | 年报公布日期 ∈ [会计期间 + 30 天, 会计期间 + 150 天] |
| 披露日完整性 | 覆盖率 > 95% |
| 无前视 | `effective_date = 年报公布日期`（而非会计期间） |
| 与时序一致 | 用披露日对齐后，因子 IC 不应异常升高（若升高说明前视） |
